# 机器人结构—执行器—控制协同优化

本仓库用于 RPO 双足机器人的跨形态三任务控制和硬件联合选型。Rough、负重和 AMP 三个专家在 2500 种结构上训练；共享策略在 400 个结构蒸馏，在 200 个独立选模结构比较，从胜出 Actor 对每个硬件候选独立联合 PPO 微调。前 50 个固定结构实测作为 BO 初始观测，之后连续搜索大腿和小腿长度，并优化膝踝电机组合。默认以原机十二项实测指标归一化，四指标权重可配置并按每轮冻结，旧评分和历史数据可复现。

正式代码集中在 `robolab/experiments/multitask_morphology/`，根目录 `start.py` 为统一启动入口，默认发布分支为 `main`。
