# 机器人结构—执行器—控制协同优化

本仓库用于RPO双足机器人的结构、执行器和控制联合优化，包含Rough、负重、AMP三个跨形态专家，以及三教师蒸馏得到共享策略的流程。

三个专家在 2500 种结构上训练，使用 4096 个环境，每组 50 种结构，每 50 次 PPO 更新换组。共享策略蒸馏从 400 种结构采集数据，在固定的 200 种结构上与教师比较。胜出模型用于后续 50 个 BO 定标结构的独立微调。正式代码集中在 `robolab/experiments/multitask_morphology/`，根目录 `start.py` 为统一启动入口，默认发布分支为 `main`。
