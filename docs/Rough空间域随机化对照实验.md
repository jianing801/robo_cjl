# Rough 空间域随机化对照实验

用同一套 2500 个 Rough 结构和 4096 个并行环境，对比每组轮换与所有结构同时训练。两者的楼梯训练工况、运动指令、奖励、全身电机扭矩约束、形态输入和 PPO 更新预算都沿用 Rough 专家设置。

| 项目 | 原 Rough 时空轮换 | Rough 空间域 |
| --- | ---: | ---: |
| 同时在场的结构数 | 50 | 2500 |
| 并行环境数 | 4096 | 4096 |
| PPO 更新次数 | 12000 | 12000 |
| 场景轮换 | 每 50 次更新 | 全程固定一个场景 |
| 首回合计时 | 每组从 0 开始 | 启动时按普通 RPO-Rough 随机错开 |

新布局循环分配环境，1596 个结构各有 2 个环境，904 个结构各有 1 个环境。同一环境在整次训练中固定使用同一个结构。每次更新仍是每环境采 24 步，共 98,304 条样本，PPO 学习 5 个 epoch，每个 epoch 分 4 个 minibatch。新入口复用 AMP 空间域的向量化采样器，每条 rollout 样本在一个 epoch 中恰好使用一次。

TensorBoard 记录原生的全局 Mean reward、PPO 指标和按电机型号汇总的健康指标。省去逐结构的 Spatial 指标，避免每个控制步生成约 10,000 个标量。计时器从启动开始记录，用时包括资产校验、场景创建、物理初始化和训练。与原轮换版比较曲线时，记录两者首回合计时设置的差别。

## 启动

在服务器仓库根目录执行，将最后的卡号改成当前空闲的卡。

```bash
conda run --no-capture-output -n robo_cjl python start.py rough-spatial --gpu 2
```

末尾加 `--dry-run` 可检查结构库和 USD 缓存登记，并预览命令。入口默认复用已迁移的 2500 结构库。使用其他已准备好的同规格库时可指定 `--root`。Rough 入口需要已有的 USD 缓存和完成证明，启动流程直接读取该缓存。输出目录为 `experts/spatial_rough_all2500_时间戳`，计时任务名为 `rough-spatial`。

全部 12000 次更新属于同一个阶段。当前入口每次启动创建独立运行目录。中断时，可在原目录查找周期保存的模型，但原生控制器的自动续训依据是已提交的完整阶段。
