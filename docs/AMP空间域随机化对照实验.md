# AMP 空间域随机化对照实验

## 实验目的

把现有 AMP 跨形态专家的“每组 50 个结构、每 50 次更新换组”与“2500 个结构同时进入 4096 个环境”对照，观察完整训练耗时和全局 `Mean reward` 曲线。空间域对照使用独立配置与输出目录，原 AMP 专家配置、检查点和日志保留。

## 两种训练方式

| 项目 | 原 AMP 跨形态专家 | 本实验：2500 结构同时训练 |
|---|---:|---:|
| 结构总数 | 2500 | 2500 |
| 同时进入场景的结构数 | 50 | 2500 |
| 环境数 | 4096 | 4096 |
| 结构分配 | 每组 50 个结构，按正式分组表轮换 | 4096 个环境按结构顺序循环分配 |
| PPO 更新预算 | 5000 | 5000 |
| 首回合计时器 | 每次换组从 0 步开始 | 启动时各环境独立随机从 0–999 步开始 |
| 每组更新后是否换结构 | 是，每 50 次更新 | 否，全程保持同一批 2500 个结构 |
| AMP 奖励、物理参数和 Actor/Critic 配置 | 现行 AMP 配置 | 沿用现行 AMP 配置 |

循环分配后，1596 个结构各有 2 个并行环境，904 个结构各有 1 个并行环境。每个结构至少进入 1 个环境；环境分配固定，不在训练中随机换形态。

专用配置为 `robolab/experiments/multitask_morphology/configs/amp_spatial_all2500.json`。它沿用原跨形态 AMP 的结构网格和全身电机力矩设置，启用 2500 个活跃结构以及表中的首回合计时方式。

## 首回合计时

空间域实验和单结构 `RPO-AMP` 共用 AMP runner 的 `init_at_random_ep_len`。开始 PPO 前，每个环境随机获得 0–999 步的起始计数。首回合可能提前超时，后续重置从 0 步计时，最多运行 1000 步（20 秒）。实验直接开始采样，首回合按普通 AMP 的规则进入 `Mean reward` 统计。对照原跨形态曲线时，应把起始计时方式也列为实验差异。

## 指标与 PPO 取样

空间域 AMP 保留全局 `Mean reward`、AMP 判别器与 PPO 训练指标、检查点和 TensorBoard。它关闭每个结构单独的 `Spatial/<结构>/reward` 与 `Spatial/<结构>/forward_velocity` 分项，避免 2500 个结构产生 5000 条逐结构指标序列。

批次采样按每个结构分组并行构造索引，不再为 2500 个结构逐个执行 Python 循环。每个 PPO epoch 中，每条 rollout 样本恰好进入一个 minibatch；不丢弃、不重复，也不改变 minibatch 数量或奖励。采样仍把每个结构的样本分散到各 minibatch，维持原有分组采样规则。多个 PPO epoch 会按算法配置重复使用同一批 rollout，这是 PPO 本身的训练规则。

采样器使用同一训练种子和同一随机分配规则，但张量实现消耗随机数的顺序不同，因此不能期待两次训练得到逐点完全相同的 reward 曲线；对照重点是运行时间和整体走势。

## 启动

在服务器仓库根目录执行，显卡编号按当时空闲卡修改：

```bash
conda run --no-capture-output -n robo_cjl python start.py amp-spatial --gpu 3
```

入口默认使用已经完成迁移的 2500 结构库，并要求该目录内已有完整 AMP 参考动作库和已登记的 USD 缓存。任一资产缺失、哈希不匹配或结构配置不一致时会停止；本命令不会生成结构、参考动作或 USD。

输出单独写入 `robolab/logs/multitask_full2500_physical_migrated/experts/spatial_amp_all2500_时间戳/`。训练计时记录也单独标成 `amp-spatial`，包括启动校验、场景加载和训练时间；运行中每小时汇报，训练中断的离线时段不计入活动运行时间。

## 对照结果怎么读

1. 用 TensorBoard 查看空间域运行的全局 `Mean reward`，与原 AMP 专家使用相同平滑口径。
2. 用独立 `amp-spatial` 计时记录读取从启动到完成的活动总时长。
3. 计时从启动入口开始，包含银行、参考动作与 USD 缓存校验、场景初始化及 PPO 更新；同时结合训练日志中的更新速度理解总耗时。
4. 这个对照回答空间域与时空轮换的训练耗时和 Mean reward 走势差异；它本身不替代最终步态评估。
