# 原机单结构专家与共享策略对照

## 目的和固定条件

共享策略从第 5 轮 DAgger Actor 出发，以新版专家先验联合 PPOAMP 在原机结构上微调 1000 次；与三个从随机策略开始、针对同一结构充分训练的单任务专家进行比较。不是重新定标 BO；正式 BO 仍使用原机第 100 代的十二项固定分母。

原机结构 `tr_792ca9f47877`：大腿 0.25 m，小腿 0.30 m，膝 DM-J10010L-2EC，踝 DM-J4340P-2EC。复用经过验证的原机预测 URDF、原生 USD及 AMP 运动学参考，不改质量、惯量、驱动器或奖励。

| 专家 | 环境 | 正式 PPO 更新 |
| --- | ---: | ---: |
| Rough | 4096 | 12000 |
| 负重 | 4096 | 12000 |
| AMP | 4096 | 5000 |

三个任务各自运行固定的一组结构，绝不每 50 代换组。保留原生观测、随机化、PPO 参数及全身扭矩约束。负重保留原生绝对代数负重课程；AMP 使用原训练源的原生计时方式。原生专家源固定于 `1b9cc2d`，实际对照运行使用在该版本上仅叠加固定结构日志、断点恢复及等字节参考动作路径校验的 Git 提交 `abfa4a6522f9789904c52e30879516cfbef9c137`，不修改 PPO 算法或物理源码。

## 启动及续训

`original_expert_comparison.py` 接受已经运行的联合微调目录和第 100 代评估目录、上述固定原生源码检出、独立输出目录。使用 `--prepare-only` 时仅检查资产及冻结单结构训练计划，不创建仿真。正式启动可提供当前联合微调监督进程的 PID 和创建时间；当其实际完成且终止后才开始占用 GPU。一次只运行一个专家；完成后自动开始下一项。若共同微调未完成或被人工暂停，不启动专家。

```bash
python -u robolab/experiments/multitask_morphology/original_expert_comparison.py \
  --shared /path/to/rpo_original_native_expert_prior_ppo1000_convergence \
  --eval100 /path/to/rpo_native_expert_prior_update100_eval \
  --native-checkout /path/to/frozen_singleton_native_checkout \
  --output /path/to/original_singleton_expert_comparison --gpu 0
```

共享训练尚未结束时追加 `--wait-pid PID --wait-create-time CREATE_TIME`。继续同一实验使用同一 Git 检出及输出，若有用户暂停标记则显式传 `--resume-paused`。只接受具有模型文件 SHA、绝对更新记录并通过原生完整状态验证的断点，恢复策略、Critic、Adam、自适应学习率、归一化与 AMP 判别器。重启本身必须重建仿真，日志中明确区分续训段；不把新回合统计伪装成连续的旧回合。中途 GPU 空间不足只等待，不抢占其他训练。最多三次同任务故障重试后停在原有数据，等待分析。

## 评估和结果

三个专家全部训练完毕后，使用同样的 200 Hz 原始采样、固定种子 20261118、20 秒工况，分别回放共享第 1000 代与对应专家最终模型。每份回放只含一台机器人并保存录像。共享 Actor 和专家 Actor 使用各自原生观测适配，不交换训练权重。成功条件为未摔倒且水平指令行程达到 20%。

`experts/{stairs,backpack,run}/` 含计划、有效检查点收据、训练回报 CSV/PNG 与计时。`evaluation/{shared,expert}/{任务}/` 含每一项回放的原始物理量、报告、录像和校验信息。`comparison.json`、`comparison.csv`、`comparison.png` 汇总原始指标、固定归一化代价及共享相对专家的百分比差异。任何任务失败都不产生该模型的综合代价。

计时累计原生 PPO 实际采样与学习耗时，包含确实执行过的重试更新，不计停机等待和资产准备时间。另列已提交更新的计算耗时。评估是单结构的固定条件对照，不据此推断全部形态或随机条件下的统计显著性。
