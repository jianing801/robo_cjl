# 原始机器人配置与正式 BO 基准

正式基准：大腿 0.25 m，小腿 0.30 m，膝关节 DM-J10010L-2EC，踝关节 DM-J4340P-2EC。使用与候选相同的 SW-GP 预测 URDF、USD 和实际运动学 AMP 参考动作，不使用厂商原始 URDF。

从经过身份验证的第五轮最终共享 Actor 独立微调200代；三任务分别固定原专家动作标准差，采用三任务原生专家训练工况、4096环境（1366/1365/1365）、PCGrad、10代 Critic 预热。原机与其他候选完全同协议，见[完整 BO 说明](三任务BO评估与结构搜索.md)。

评估采用同一固定种子、20秒、200 Hz 采样和四指标。原机十二项实测值分别作为固定分母，每项候选指标除以原机值再按任务内权重加权；原机三个任务及综合代价均为1。三项都成功才参加综合排名。禁止使用100代旧分母或1000代备用模型。

当前200代正式基准尚需实测后冻结，不预填假定分母。执行 BO 文档中的 `reference` 和 `freeze-scoring` 命令。
