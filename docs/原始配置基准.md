# 原始 RPO 配置的三任务基准

这个实验用原始 RPO 的腿长和膝踝电机，按本轮 BO 的协议微调和评估。设计编号为 `tr_792ca9f47877`，四项输入如下。

| 输入 | 原始配置 |
| --- | --- |
| 大腿长度 | 0.25 m |
| 小腿长度 | 0.30 m |
| 膝电机 | `DM-J10010L-2EC` |
| 踝电机 | `DM-J4340P-2EC` |

腿长取原始 URDF 中相应关节原点的竖直距离。踝俯仰关节还有约 20.85 mm 的侧向偏移。这个精确组合位于 2,500 个专家训练格点之外。按本轮 BO 的 SW-GP 和 URDF 生成流程重建该配置，保留相同的质量、质心和惯量预测方法，以及力矩曲线、原生任务动力学和全身扭矩约束。共享策略仍使用原训练结构库冻结的形态输入尺度，对这台机器重新计算其物理输入。历史实验中替用 RS06 的测量对应另一个电机配置。

## 微调和评估协议

| 环节 | 配置 |
| --- | --- |
| 初始策略 | 当前 BO 使用的第 5 轮获选共享策略 |
| 微调 | 新版 `shared_native_ppoamp_expert_prior_v4`，先做 10 次独立 Critic 预热，再做 100 次正式联合 PPO 更新。4096 个环境，上楼、负重、跑步分配 1366、1365、1365 个 |
| 上楼 | 0.5 m/s，级高 7.5 cm、踏面深 30 cm，从底部平地中央起步 |
| 负重 | 0.5 m/s，平地直行，背负 10 kg |
| AMP 跑步 | 1.5 m/s，平地直行，使用与生成 URDF 运动学匹配的八段参考动作 |
| 评估 | 每项 20 秒，固定种子 `20261118`。策略每 20 ms 给一次动作，原始物理量每 5 ms 采样 |

每项完成 20 秒、期间未摔倒、水平净前进行程达到指令行程的 20% 时记为成功。每项保留绝对机械 CoT、正机械 CoT、速度 RMSE、横滚俯仰合成角速度 RMS 和最大膝踝持续额定扭矩占比。新版四指标 BO 用原机的十二项指标作为固定分母，以 `候选值 / 原始配置值` 归一化。原机三项任务和按 `0.4 / 0.3 / 0.3` 加权后的综合代价均为 1。[正式 BO 协议](三任务BO评估与结构搜索.md#第二步用原机基准冻结评分)

## 复现单结构实验

如需独立复现该算法的 100 代微调，使用相同结构、同一个共享 Actor、三个专家的 Critic 和探索参数及相同评估工况，详见[原生 PPO 微调](共享策略原生PPO微调说明.md)。新运行使用独立输出目录。正式 BO 前 50 个结构和后 50 个新增候选均须使用该 V4 协议。

在本实验的代码检出目录执行。以下目录按租卡部署填写。`native_entry` 指向正式 BO 计划绑定的原生环境源码，生成的结构库以这套源码身份验收。`asset_source` 提供几何模板和显示网格，输出的物理 URDF 由 SW-GP 生成。HHTools 使用独立的 `amp_hhtools` 环境和 `native_entry` 所在仓库的数据目录。[环境与资产准备](环境与资产准备.md)

```bash
entry="$PWD/robolab/experiments/multitask_morphology"
native_entry=/data/chenjiale/robo_cjl/robolab/experiments/multitask_morphology
train_python=/root/sj-tmp/envs/robo_cjl/bin/python
reference_python=/root/sj-tmp/envs/amp_hhtools/bin/python
asset_source=/data/chenjiale/robo_cjl/robolab/data/robots/roboparty/rpo
experiment=/data/chenjiale/robo_cjl/robolab/logs/multitask_full2500_physical_migrated
continuation=/root/sj-tmp/shared-distill-20261121/shared_policy_round5
work=/root/sj-tmp/bo-ppo100-round5-data/rpo_original_reproduction
assets="$work/approved_native"
config="$entry/configs/rpo_original_configuration.json"

"$train_python" "$native_entry/engine/prepare_bank.py" --generate-assets --config "$config" \
  --template "$asset_source/urdf/rpo.urdf" --mesh-dir "$asset_source/meshes" \
  --output-dir "$assets/banks/rough"
"$train_python" "$native_entry/engine/prepare_bank.py" --generate-assets --config "$config" \
  --task-key backpack --rough-bank "$assets/banks/rough/bank.json" \
  --output-dir "$assets/banks/backpack"
"$train_python" "$native_entry/amp_engine/prepare_bank.py" --generate-assets --config "$config" \
  --rough-bank "$assets/banks/rough/bank.json" --output-dir "$assets/banks/amp"
"$reference_python" "$native_entry/amp_engine/prepare_references.py" \
  --bank "$assets/banks/amp/bank.json" --output "$assets/references" \
  --hhtools-root "$native_entry/amp_engine/vendor/hhtools" \
  --device cuda:0 --warp-cache "$work/warp_cache"
```

三份结构库和参考库均校验完成后，在资产目录建立身份记录供运行入口复核。

```bash
"$train_python" - "$assets" <<'PY'
import hashlib
import json
from pathlib import Path
import sys

assets = Path(sys.argv[1])
banks = {task: assets / 'banks' / task / 'bank.json'
         for task in ('rough', 'backpack', 'amp')}
library = assets / 'references' / 'library.json'

def sha(path):
    return hashlib.sha256(path.read_bytes()).hexdigest()

record = dict(design_id='tr_792ca9f47877',
              banks={task: sha(path) for task, path in banks.items()},
              library_sha256=sha(library))
with (assets / 'assets_ready.json').open('x', encoding='utf-8') as stream:
    json.dump(record, stream, indent=2)
PY

PYTHONPATH="$PWD/robolab:$PWD/rsl_rl" "$train_python" -B -u "$entry/reference_bo.py" \
  --root "$experiment" --shared-continuation "$continuation" \
  --assets "$assets" --output "$work/evaluation" --gpu 0
```
