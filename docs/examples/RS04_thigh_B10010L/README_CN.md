# RS04 大腿：DM10010L B 方案 CAD 对齐与 SW 扫描宏

本目录是一套大腿端样例，与小腿的 DM-J6216P 示例采用不同的坐标基准。使用前先阅读本说明；B 方案不是输出端面中心对齐。

## 文件

- `RS04_对齐DM10010L_B方案.step`：RS04 按 DM10010L 控制器侧壳体基准面对齐后的几何 STEP。
- `scan_rs04_thigh.bas`：RS04 大腿装配体扫描宏，源码仅含 ASCII 字符，中文对象/坐标系名称由 `ChrW` 构造。

## CAD 对齐规则：DM10010L 的 B 面

- 按用户确认的 B 方案，使新电机的控制器侧壳体端面中心与旧 DM10010L 的对应 B 面中心重合，同时令主轴线重合；不把输出端面设为共同原点。
- RS04 源 B 面中心为 `(0, 0, 25) mm`，目标 B 面中心为 `(0, -27.7354762344509, 0) mm`。源到目标的映射为：

  ```text
  x_target =  x_source
  y_target =  z_source - 52.7354762344509 mm
  z_target = -y_source
  ```

- 轴向关系：源 `+X → +X`、`+Y → -Z`、`+Z → +Y`，为右手坐标系；仅刚体旋转和平移，不缩放、不镜像。沿电机轴未额外转动，属于既定零滚转约定，并非由安装孔或线缆方向确认的实机周向配准。
- 对齐后 RS04 的 B 面中心位于 `(0, -27.7354762344509, 0) mm`，输出安装面位于 `Y=-79.9354762344509 mm`。默认原点仍在旧 10010L 框架原点，不在新电机实体中心；这是 B 方案的定义。
- STEP 几何经独立 CAD 内核核验：保留 43 个封闭实体、5060 个面；纯刚体变换相对同源 STEP 读写基线的几何核验误差低于 `1e-6`。当时旧 10010L STEP 原文件不可读取，参考 B 面位置沿用已有完整几何审计记录；对齐副本也未能在 SolidWorks 中二次打开复核（内存警告），因此不要宣称其机械孔位、干涉或 SW 导入状态已验证。
- STEP 只含几何，不携带 SolidWorks 的手工质量/质心/惯量覆盖，也不表示 RS04 已与大腿支架完成真实机械适配。

## 大腿扫描宏

- 宏针对 RS04 大腿装配体工作副本，扫描整个腿部结构属性；不是单电机质量属性扫描。
- 单独打开控制大腿长度的“大腿3”零件，并确认全局方程变量 `deltl`；装配体必须有“坐标系1”。质量属性按 SI 单位计算并包含隐藏实体/零部件。
- `deltl=10,20,…,150 mm`，共 15 点；以 `0.25 m + deltl` 换算，样本腿长为 `0.26–0.40 m`。`0.25–0.26 m` 不在该扫描点集中，预测时属于下端外推。
- 装配体占位组件名称可能仍显示 `dm-j10010l`，但运行前必须确认其电机质量属性已覆盖为 RS04 参数。
- 首点防错值（坐标系1、`deltl=10 mm`）：质量 `2.29882456 kg`，质心 `(0.00064559, -0.01227559, -0.21356263) m`；质心处正惯性积记法 `Lxx=0.01830738`、`Lyy=0.02000587`、`Lzz=0.00302357`、`Lyz=+0.00127222 kg·m²`。值不匹配时停止，先检查型号覆盖、装配体配置和坐标系，不能直接改宏内校验常量。
- CSV 和状态文件写入活动装配体副本所在目录，文件名包含时间戳。宏会尝试恢复原 `deltl`、重建零件和装配体，但不会保存 CAD 文件。需检查状态为 `SUCCESS` 且 CSV 有 15 行 `sample` 记录。

## 使用边界

此例展示 B 方案大腿模型与其对应扫描宏的文件/说明格式。新电机需重新识别 B 面、轴线、绕轴方向、质量覆盖和首点截图值；不得照搬此处的平移量、`CHECK_*` 常量、腿长和坐标系设置。若目标采用 DM4340 基准，应改用输出端面中心方案，而不是 B 方案。
