## BO 运行逻辑

- 连续变量：大腿长度 0.25–0.40 m、小腿长度 0.30–0.45 m。
- 离散变量：默认膝从上表 5 款选一、踝从上表 7 款选一；每个试验同步换用对应执行器曲线、armature 和 SW-GP。
- `--list-motor-candidates` 只列入口与状态，不启动仿真。
- 任何 GP 缺文件、段位不符、坐标系元数据不一致、执行器输入缺失或曲线缺失，都会在 BO 开始前阻止运行。
- Study protocol 固定候选列表，并对包络、GP 索引、每个 GP JSON、旧模型索引和生成器记录 SHA-256；更改模型后必须用新的 study/database。

示例（完整候选池，实际长时间训练参数由用户自行设定）：

```bash
python robolab/scripts/tools/co_design.py --list-motor-candidates
```

`motor_urdf_gp_registry.json` 是唯一 URDF 结构模型索引，所有候选只通过
独立 GP JSON 预测。旧多项式索引、回退逻辑和拟合脚本已移除。RoboParty 的
legacy 矩形执行器默认及原始 RPO_CFG未改变；legacy 别名对应的 URDF 质量属性
也由当前 GP 预测。
