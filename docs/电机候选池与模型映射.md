# 电机候选池与模型映射

本文是当前候选状态的人类可读索引。代码与机器可读文件是最终依据；如果此页和运行数据不一致，以代码、CSV 和 GP 注册表为准。

## 当前 BO 候选

当前共 12 款：膝关节 5 款、小腿/踝关节 7 款。每行中的 SW-GP 模型 ID 和关节段是一一对应的。

| 关节 | 电机型号 | SW-GP 模型 ID |
|---|---|---|
| 膝 | RS04 | RS04_thigh |
| 膝 | DM-J10010L-2EC | DM10010L_thigh |
| 膝 | DM-J10010-2EC | DM10010_thigh |
| 膝 | DM-J6248P-2EC | DM6248P_thigh |
| 膝 | DM-J10422P-2EC | DM10422P_thigh |
| 踝 | RS06 | RS06_calf |
| 踝 | DM-J4340P-2EC（原款） | DM4340P_calf |
| 踝 | DM-J8009P-2EC-V1.1 | DM8009P_V11_calf |
| 踝 | DM-J4340P-2EC-V1.1-48V | DM4340P_V11_48V_calf |
| 踝 | DM-J8006-2EC-V1.1 | DM8006_V11_calf |
| 踝 | DM-J4310P-2EC-48V | DM4310P_48V_calf |
| 踝 | DM-J6216P-2EC | DM6216P_calf |

DM-J10010（非 L）和 DM-J10010L 是两个不同型号，分别使用独立的执行器曲线、armature 和 SW-GP 模型。4340P 原款、4340P V1.1，以及其他硬件/电压版本也分别登记，不因名字接近而共用数据。

BO_READY 代表运行所需的曲线、armature 和对应结构模型均已登记，不代表每条扭矩—转速包络都经过实机台架验证。DM-J6216P 的 260 rpm 按用户指定作为 48 V 建模端点，不应表述为已由厂家资料确认的 48 V 空载转速。DM-J8520P 当前不在候选池：其参数模型平台与厂家峰值上限存在未解决差异，故不应恢复到运行入口。

## 各文件负责什么

| 路径 | 用途 |
|---|---|
| robolab/robolab/assets/rpo_motor_catalog.py | 代码中的精确型号白名单、执行器规格与候选入口 |
| robolab/robolab/assets/motor_data/selected/bo_ready_candidates.csv | 每款电机的关节、模型 ID、扭矩曲线 CSV、armature 和模型文件映射 |
| robolab/robolab/assets/motor_data/motor_urdf_gp_registry.json | GP 模型 ID、腿段、训练范围、预测范围及 JSON 文件 |
| robolab/robolab/assets/motor_data/urdf_gp_models/ | 训练、评估和 BO 运行时读取的 SW-GP JSON |
| robolab/robolab/assets/motor_data/torque_speed_curves/ | 每款候选电机各自独立的扭矩—转速曲线 CSV |
| robolab/robolab/assets/motor_data/urdf_gp_sources/ | SW 原始扫描、拟合脚本、模型源文件、误差与物理检查、图表 |

每台电机保留独立曲线，便于单独修订；不能把不同型号的曲线合并成一条或相互替代。SW 结构模型同样按“电机型号 × 腿段”隔离；即使两版电机使用了相同 SW 扫描数据，也保留独立模型 ID 和配置。

## 腿长范围与结构模型

预测允许范围以 motor_urdf_gp_registry.json 为准：大腿为 0.25–0.40 m，小腿为 0.30–0.45 m。训练范围并不总等于预测范围：

- RS04、DM-J10010L 大腿的训练范围为 0.26–0.40 m；0.25–0.26 m 是端点外推。
- 其他当前大腿模型的训练范围为 0.25–0.40 m。
- 当前小腿模型的训练范围为 0.31–0.45 m；0.30–0.31 m 是端点外推。

候选和曲线预检可在不启动仿真的情况下运行：

    python robolab/scripts/tools/co_design.py --list-motor-candidates

原 RoboParty 的两个 legacy 矩形执行器默认配置保持不变。legacy 结构模型选项和执行器矩形/动态限幅是不同设置；不要把“legacy URDF”误认为某种电机曲线模式。
