# 基于 SW-GP 的 URDF 更新

本文说明结构 GP 的运行接口和物理量约定。当前电机清单及型号绑定见[电机候选池与模型映射](电机候选池与模型映射.md)。

## 数据来源与模型输入

运行入口为 robolab/scripts/tools/generate_urdf_sw.py。它根据膝、踝电机 ID 查找对应腿段的 GP 模型；型号—腿段—预测范围的唯一注册表是 robolab/robolab/assets/motor_data/motor_urdf_gp_registry.json。运行时读取独立 JSON，不使用旧多项式模型回退。

每个长度点拟合 10 个结构量：质量、三维质心，以及关于整体质心的对称惯性张量六项。SW 扫描宏可额外输出主惯量和惯性主轴用于检查，但这两者不是 GP 的目标量。输入应取 SW 中“由重心决定，并且对齐输出坐标系”的惯性张量，而非关于坐标系原点的张量。

SolidWorks 使用正惯性积记法。生成 URDF 标准惯性矩阵时，将三个非对角惯性积取负；质心张量无需再次做平行轴平移。具体字段选择和扫描验证见[SW 数据获取流程](SW数据获取与新电机交接完整流程.md)。

## 写入内容

- 大腿结构属性写入 left/right_thigh_pitch_link，小腿结构属性写入 left/right_knee_link。
- 质量、三维质心和六个惯性分量由对应电机、对应腿段的 GP 预测，不能跨电机复用。
- 膝与踝关节的 z 向安装位置随腿长更新；其余轴向、x/y 位置和关节配置按原模板保留。
- 碰撞盒代表连杆中段：固定近端/远端安装间隙，仅调整中间段的 z 向长度，不对整盒做等比例缩放。
- 视觉网格不会随腿长自动变形；若需准确外观或网格碰撞，需另行更新 CAD/网格。

坐标变换定义为 c_link = Q c_SW + t，I_link = Q I_SW Qᵀ。默认假设 SW 数据已与左侧 link 坐标对齐，右侧按 y 方向镜像；只有在装配体/坐标基准已核实的情况下才使用此默认。若 CAD 轴向或原点不同，应提供明确 frame-map，不可用惯性主轴代替安装坐标轴。SW 对齐规则和两个样例见 SW 流程文档及 docs/examples/。

## 单独生成文件

在安装了项目依赖的环境中，使用原始 URDF 模板和网格目录生成到一个尚不存在的输出目录：

    python robolab/scripts/tools/generate_urdf_sw.py --thigh 0.30 --calf 0.35 --knee-motor RS04 --ankle-motor RS06 --template /path/to/rpo.urdf --mesh-dir /path/to/meshes --output /tmp/rpo_sw_030_035

命令需提供大腿、小腿长度和输出目录；模板或网格未包含在当前克隆时，按上例显式指定。可通过 aligned-side 指定已对齐的侧，或用 frame-map 提供四个 link 的旋转矩阵和平移。模型会拒绝预测范围外长度、缺失模型、非物理惯量、缺失网格、输入输出相同，以及覆盖已存在的输出。

输出文件为 output/urdf/rpo.urdf，旁边生成 rpo.report.json，记录电机型号、使用的模型 ID、预测属性、坐标变换和外推状态。每次用新的输出目录，以免覆盖既有结果。

## 验证边界

脚本会检查质量为正、输入/预测结果有限、惯性矩阵正定且满足主惯量三角不等式，并在 report 中标记训练范围外预测。通过这些检查只表示格式与基本物理一致性通过，不等于 CAD 质量、惯量预测精度或实机动力学已经验证。

联合 BO 的候选列表、曲线与 SW-GP 绑定由电机目录和预检逻辑读取；模型或曲线变化后应使用新的 study/database，避免混合不同物理模型的结果。
