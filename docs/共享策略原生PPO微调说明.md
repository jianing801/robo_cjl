# 三任务共享策略：原生 PPO 微调

2026-11-25 修复方案。前一版原机 1000 代实验中，虽然上楼较稳定，负重和 AMP 每步奖励及固定工况运动性能均退化。这不是单纯的 Mean reward 回合统计问题。当前修改尽量沿用三个专家的训练机制，不修改蒸馏、教师、结构库、原生物理量、训练奖励定义或 BO 工况。

## 参数与必要适配

| 项目 | 设置 |
|---|---|
| 仿真 | 单进程、4096 环境，三任务 1366 / 1365 / 1365 个 |
| 起始 Actor | 同一第五轮获选蒸馏策略；输入、十帧历史和任务门控不变 |
| 共享 Critic | 各任务原生特权观测；独立归一化后共享价值网络 |
| Critic 预热 | 10 次只训练 Critic；正式 Actor 更新从 0 开始计数 |
| 每代采样及优化 | 24 步、5 epoch、4 minibatch；原生 RSL-RL PPOAMP |
| GAE | γ = 0.99，λ = 0.95 |
| 裁剪和梯度 | PPO 比例 0.2，价值损失裁剪开启，价值损失系数 1.0，最大梯度范数 1.0 |
| 学习率 | 初始 1e-4、原生 KL 自适应、目标 KL 0.01 |
| 探索 | 初始动作标准差 1.0、可学习 |
| 熵系数 | 上楼 0.005，负重 0.005，AMP 0.01 |
| 对称 | 上楼、AMP 按各自原生左右镜像增强、镜像损失系数 0.2；原生负重配置未开启镜像，其联合批次使用恒等变换，不施加镜像损失 |
| AMP | 独立复制教师判别器及其已训练归一化器，恢复原生 LSGAN 判别器同步训练，只使用本结构对应的 AMP 轨迹及参考动作 |

共享学习率采用 AMP 的原生初始值，其他不同任务的熵系数按各自原生配置处理。Actor 部署文件仍为单个共享 Actor，不包含 Critic 的特权输入。独立 Critic 预热是针对训练好 Actor、新 Critic 的必要适配，判别器和 Actor 在该阶段不更新。

## 对照实验与后续搜索

使用原始结构（大腿 0.25 m、小腿 0.30 m、膝 DM-J10010L-2EC、踝 DM-J4340P-2EC），同一第五轮共享 Actor、相同随机种子和工况，另建实验目录。完成代码测试、单次真实更新核验后，按 1000 次正式 PPO 更新组织对照。第 0、100、200、500、800、1000 代策略及原始评估都保留。记录总体及各任务 Mean reward、每步奖励、KL、学习率和实际物理性能。旧版训练的原始测量数据不可修改。

在租卡新代码检出目录执行（数据盘目录保留历史实验）：

```bash
/root/sj-tmp/envs/robo_cjl/bin/python robolab/experiments/multitask_morphology/native_ppo_convergence.py \
  --legacy-run /root/sj-tmp/bo-ppo100-round5-data/rpo_original_025_030_10010l_4340p_ppo1000_convergence \
  --output /root/sj-tmp/bo-ppo100-round5-data/rpo_original_native_ppo1000_convergence \
  --gpu 0
```

入口先执行独立的 10 次 Critic 预热与 1 次真实联合更新检查，核实 4096 × 24 样本及三任务 KL，再从原始共享 Actor 开始独立的 1000 次正式更新（另有 10 次 Critic 预热）。仅进行前一项检查可加 `--smoke-only`，随后在同一输出目录执行完整命令复用已验收检查。人工暂停后需明确加 `--resume-paused`。

若本轮只检验训练曲线与收敛趋势，在命令末尾加 `--training-only`：保留 1000 代训练及里程碑断点，生成 Mean reward 图和每代 PPO 诊断 CSV，不开启任何固定工况评估。对于新版本正在运行的实验，在输出目录建立 `SKIP_EVALUATION` 标记也可在训练完成后跳过评估。已完成的训练可用 `--summarize-trained`（相同 `--legacy-run` 与 `--output`）只读生成训练图表，不启动训练或评估。

评价采用原有 20 秒、200 Hz 固定工况和四指标体系。Mean reward 不能单独证明策略收敛或新方案消除退化；需要真实轨迹及性能指标对照。该说明为实验设计和实现口径，不预设 1000 代对照实验的结果。

在完成上述验证前，正式 BO 保持暂停。验证通过后，原机和初始 50 个结构需使用同一种原生 PPO 算法、相同起始 Actor、相同正式微调代数及评估工况重新定标。再进行新增候选。旧版原机、50 个初始观测、BO 结果可原样复算，但不能和新方案组成同一优化数据集。

## 断点保存

每代提交保存原始 Actor、完整共享策略及价值网络、归一化器、动作标准差、PPO 与 AMP 的 Adam、KL 调度后的学习率、判别器及其归一化器、AMP 缓冲区和随机状态，并绑定算法身份 `shared_native_ppoamp_v3`。保留第 0 代、各里程碑和最近两次完整学习状态，以及每代轻量提交记录及原始奖励数据。仿真场景/回合重启不能视作恢复了 PhysX 隐藏状态。旧学习状态不兼容新 Critic；不得用旧断点冒充原生 PPO 续训。旧策略依然可以独立固定工况评估。
