# 跨品牌电机进入腿长—电机协同优化的资料清单

本文后续内容是未入选跨品牌型号的历史调研清单，不代表当前BO白名单。当前代码入口与12个已就绪型号请看[电机BO候选池与GP映射](电机BO候选池与GP映射_2026-10-17.md)；跨品牌候选仍未加入。

本文件区分两件事：**型号进入离散设计变量目录**，以及**型号具备可信数据、能够参与 BO 训练**。前者已完成；后者必须逐型号满足下列输入，不以别的电机曲线、固定 `armature=0.01` 或其他装配体 URDF 代替。运行 `python robolab/scripts/tools/co_design.py --list-motor-candidates` 可查看当前状态。默认优化池仍为膝 `RS04 / DM-J10010L-2EC`、踝 `RS06 / DM-J4340P-2EC`。

### 现阶段不能把普通厂家性能图直接叫作“真实峰值包络”

CubeMars 的分析图提供某种负载工况下的转速—扭矩关系，但图线未必是控制器允许的峰值输出边界。以 `AK10-9-V3` 为例，48 V 分析图的零扭矩端约在 245 rpm，而产品页给空载 320 rpm；两者工况/含义未核实前，不应把这条线接到 320 rpm 并标成厂家实测包络。MyActuator 的电气参数可以支持参数化推算，但电流定义、控制器电压利用率和限流/弱磁策略必须核对；推算曲线仍需标注假设。宇树公开的 `IM6014` 图是 60 V，不可原样当作 48 V 曲线。

## 每个型号需要提交什么

1. **电机身份与工作条件**：精确版本、供电固定 48 V、驱动器/固件版本、连续与峰值持续时间、转速和扭矩使用的输出轴定义。优先获取厂家 48 V 峰值扭矩—输出转速 CSV/图（附测试电压、温度和电流限制）；若只能给电气参数，则还要相电阻、相电感、反电势/转矩常数的单位和口径、峰值电流的 RMS/峰值口径、控制器母线电压利用率和弱磁/热限流规则，模型输出必须标为“参数推算”。
2. **关节侧等效惯量**：最好由厂家给低速端/输出端等效惯量。若仅有转子惯量 `J_rotor`，记录其测量轴和是否已含减速器，再计算 `J_rotor × N²`；这通常只是下限，不能把执行器整体刚体惯量或不明轴的 `Inertia` 字段直接填到 `armature`。代码里已保留厂家转子惯量字段，但新型号的 `armature_kgm2` 均为 `None`。
3. **机器人装配体质量属性**：不是电机单独 STEP 的质量属性。将该电机装进实际大腿/小腿 SolidWorks 装配体，保持相同零件材料、坐标系与电机安装姿态。每个长度导出 `length_m, mass_kg, com_x_m, com_y_m, com_z_m, Ixx, Ixy, Ixz, Iyy, Iyz, Izz`（质心惯量、明确 SW 惯性积符号）。大腿覆盖 0.25–0.40 m，小腿覆盖 0.30–0.45 m；沿用现有方案的 15 个拟合点与 5 个独立验证点，分别核对质量、质心和惯量误差。两端安装段保持几何不变，仅中间腿杆长度变化。
4. **几何/安装核对**：厂家 STEP、安装孔位、轴向、线束空间、碰撞体与运动干涉。改变型号若需要改变腿部外形或安装件，也要在装配体和碰撞体模型中体现。

## 接入与验收顺序

1. 将峰值包络导出为 `robolab/robolab/assets/motor_data/<ID>_peak_envelope.csv`，列名为 `output_speed_rad_s,peak_envelope_nm`。首点零速，末点为该 48 V 版本空载转速且零扭矩；中间速度严格递增、扭矩非增。记录原始读点、厂家图版本及模型假设。若原图并非峰值包络，不能只靠 GP 插值就变成真实峰值包络。
2. 根据独立 SW 装配体数据，为“电机型号 × 腿段”分别拟合 GP；不得跨型号或大小腿复用结构模型。把经过验证的模型保存为独立 JSON，登记到 `motor_urdf_gp_registry.json`，并同时保留拟合输入、预测范围、交叉验证/误差报告和惯量物理检查结果。运行时只接受注册的 GP，不再使用旧多项式模型或回退路径。

   可按 `docs/templates/motor_sw_mass_properties.csv` 记录质量、质心和质心惯性张量；`split` 列区分拟合点与独立验证点。模型训练、单位与坐标系检查、惯性符号转换和全预测范围的正定性/主惯量三角不等式检查通过后，才把 GP JSON 加入注册表。此步骤不生成 CAD 数据，也不自动决定误差是否满足研究要求。
3. 在 `rpo_motor_catalog.py` 中填入 `torque_speed_curve_csv`、核实过的 `armature_kgm2`/来源、`urdf_model_id`。预检会核对所选曲线与 SW 模型；缺项时立即停止，不启动 Isaac Sim，也不创建新 study。
4. 先做单电机训练/评估 smoke test，再加入多电机 BO。只要曲线、URDF 或惯量模型改变，须使用新的 `--db` 和 `--study-name`，以免把不同物理模型的 trial 混在一起。

四个已有电机仍可直接运行。要查看新候选但不启动训练：

```bash
python robolab/scripts/tools/co_design.py --list-motor-candidates
```

尝试选未完成数据的型号会在预检阶段列出缺项，例如：

```bash
python robolab/scripts/tools/co_design.py --knee-motors RS04 --ankle-motors AK70-9-V3 --trials 1
```
