# 三任务跨形态专家与共享控制策略

**日常启动不需要手工拼路径：直接看[快速启动](../../../快速启动.md)。** 本页只说明配置与底层入口。

这是当前正式代码目录：Rough楼梯、负重行走、AMP跑步三个跨形态专家，以及三教师共享Actor的BC/DAgger融合。

**启动操作统一看 [完整流程](../../../docs/完整流程.md)**，其中包含每个新终端的路径设置、真实资产默认位置、首次结构库生成、独立CPU/GPU参考生成、三任务启动及续训命令。已完成的准备阶段直接跳过，避免反复创建或覆盖输出。

## 文件入口

| 文件/目录 | 用途 |
|---|---|
| `prepare.py` | 基础URDF只生成一次，绑定三个bank并联合审计 |
| `train.py --task rough/backpack/amp` | 三专家统一入口，执行训练需要`--execute` |
| `configs/` | 三个正式配置，绑定同一冻结均衡排表 |
| `engine/` | 公共轮换、场景、PPO、负载和全身力矩逻辑 |
| `amp_engine/` | AMP原生观测/优化器、参考动作及固定HHTools快照 |
| `amp_engine/prepare_references.py` | 独立CPU/GPU参考生成，不训练 |
| `audit_banks.py` | 三个bank、实际URDF及电机一致性复核 |
| `validate_teacher.py` | 内部任务名`stairs/backpack/run`，检查完整模型与链身份 |
| `prepare_shared.py` | 三个已完成教师绑定为全共同结构库计划 |
| `distill.py` | 立即执行BC/DAgger及全库配对评估，无`--execute`参数 |
| `shared_policy/` | 共享网络、观测适配、采集、训练和录像 |
| `scheduling/formal_schedule.json` | 已冻结的正式分组表，训练不重新搜索 |

## 正式参数与物理

| 项目 | 当前设置 |
|---|---|
| 完整结构库 | 10×10×5×6＝3000种 |
| 大腿/小腿 | 0.20–0.40m / 0.25–0.45m，各10个等间距点 |
| 并行副本 | 4096环境，每组60种，每种68或69个副本 |
| 轮换 | 每组50次PPO更新，50组全库一轮＝2500更新 |
| 任务预算 | Rough/负重各12000更新；AMP 5000更新 |
| 全库轮数 | Rough/负重4轮＋第5轮40组；AMP完整2轮 |
| 原生形态条件 | 29维；类别按完整库编码，不随当前组改编号 |
| GP | 允许已授权范围外推，保留模型与质量/惯量审计 |

膝5款：RS04、DM-J10010L-2EC、DM-J10010-2EC、DM-J6248P-2EC、DM-J10422P-2EC。

踝6款：RS06、DM-J4340P-2EC、DM-J8009P-2EC-V1.1、DM-J4340P-2EC-V1.1-48V、DM-J8006-2EC-V1.1、DM-J6216P-2EC；不含4310P。普通4340P与V1.1-48V不是同一个电机参数。

其余固定腿部电机用10010L，肩与臂用普通4340P。全身23关节按对应电机曲线硬约束，额外软惩罚为：

```text
-12 × control_dt × sum(max(abs(actual_torque)/available_torque - 0.8, 0)^2)
```

步长只乘一次，旧六关节软惩罚关闭。动态可用力矩接近零时不做除法，该关节从此项中排除并单独统计；这不是额外的超速惩罚。非有限数据不能伪装成零成本。

Rough与AMP复用基础机器人；负重增加独立背包体，0.30kg是模板初始化质量，运行时由原负载课程覆盖，不重复叠加。负重课程按绝对更新0–999、1000–2999、3000+推进，换组不从头开始。

AMP保留原生三帧、按项排列的教师观测及训练归一化器，共享学生用十帧流式适配。新运动学必须有匹配参考；同运动学可按身份复用，不按近似腿长猜测。

## 正式分组与身份

采用 [离线验证过的精确构造与退火顺序](scheduling/分组算法与验证.md)，冻结种子43结果：每组30种电机组合各2种，每档大腿/小腿各6种，整轮不重不漏。

每轮保持组成员和组顺序，保留循环窗口覆盖。组内已独立打散，跨轮旋转`cycle×16 mod60`个槽位，分散4096/60多出的16个副本。排表SHA256、加载器SHA256和配置进入实验身份；哈希、网格或容量不符则拒绝。

改变源码/奖励/物理/分组不能直接续旧run。旧源码已归档，旧实验、模型、原始资产与参考动作未移动。已有合法bank和完整参考库可作为新实验输入，是否可用以原生身份校验为准。

## 输出和验收

[实验文件说明](../../../docs/结果归档与录像索引.md)列出bank、library、plan、commit、模型和评估证据。`completed.json`首先代表预算完成，不等于行走成功。

[评估与录像](../../../docs/评估与录像.md)给出三任务教师/学生对照。名义门槛：完整20秒、不摔、前进速度至少0.1m/s，楼梯另需上升至少0.1m；忽略横移，不把MSE或训练reward当通过。

BC/DAgger输出的是共享Actor，尚不等于共享PPO微调；固定结构PPO实验及独立历史Rough BO的限制见 [扩展说明](../../../docs/优化与扩展边界.md)。不要把历史200结构结果当作新3000结构结果。
