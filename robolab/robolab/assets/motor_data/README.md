# 电机数据目录

这里保留运行所需数据、当前选型索引，以及能复现模型的源资料。当前候选和型号映射见[仓库文档](../../../../docs/电机候选池与模型映射.md)；SolidWorks 采集与新电机交接流程见[仓库文档](../../../../docs/SW数据获取与新电机交接完整流程.md)。

## 根目录运行文件

| 文件 | 用途 |
|---|---|
| motor_urdf_gp_registry.json | 唯一的 URDF 结构 GP 注册表：映射电机 ID、大腿/小腿段、训练/预测范围和 GP 文件。 |
| torque_speed_curves/ | 每款当前候选电机各自独立的扭矩—转速运行 CSV。曲线不能跨电机替代。 |
| DM_selection_2026_09_23.csv | 用户提供的达妙选型表数据整理副本，用于来源核对；不是执行器曲线或 GP 模型。 |

## 子目录

- urdf_gp_models/：训练、评估和 BO 直接读取的 SW-GP 模型 JSON。
- urdf_gp_sources/：原始 SW 扫描、拟合脚本、MATLAB 模型、图表和误差/物理检查；不是运行时查找目录。原 RoboParty 四款基准电机的当前 SW 扫描与 GP 资料也保留在这里。
- selected/：纳入选型的参数资料和 BO 映射表。
- not_selected/：未纳入选型的候选及来源归档；不参与运行。
- torque_speed_curves/：每款候选电机的独立曲线文件，便于按型号单独修订。

## 参数与模型口径

选型表中的原始参数、单位和厂家版本需保留，不应直接把模型假设写回源数据。R/L、电流和惯量字段的定义应按对应型号说明书核对；若用于参数化扭矩—转速模型，必须记录相/线、峰值/RMS、dq 轴及电机/减速器轴侧等假设。转子惯量只有在确认其为电机侧时，才可按减速比平方换算为关节侧等效惯量；该换算不自动包含齿轮系惯量与损耗。

执行器 CSV 可能来自厂家曲线整理，也可能是基于公开参数和已声明假设生成的参数模型包络。GP 插值/拟合的平滑度或交叉验证误差不能证明曲线经过实机台架验证。当前每台电机的具体来源及假设以其资料目录、候选映射和代码为准。

URDF 质量属性 GP 每个“电机型号 × 腿段”独立维护。型号版本不同，即使 SW 扫描值相同或扭矩参数相近，也不自动共用 GP 注册 ID、执行器曲线或物理参数。

旧 URDF 多项式模型索引和多项式拟合回退已移除；结构预测统一使用各自 GP。
