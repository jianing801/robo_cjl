# DM-J4340P 小腿装配体 URDF 参数 GP 拟合

坐标系2；输入15个SW点，实测长度 0.31–0.45 m。预测域为0.30–0.45 m，0.30–0.31 m为外推区，无扫描点验证。

质量、质心 xyz 和质心处惯性张量的6个独立分量分别用 Matérn 5/2 高斯过程拟合。核长度尺度和噪声项在由粗到细的对数网格上，以精确边际似然最小值选择。各输出单独标准化。该实现仅依赖 NumPy。

精度采用嵌套留一交叉验证：每折留出1点，并在其余14点重新选择超参数。它不是独立外部测试集。拟合观测噪声是 GP 正则化参数，不代表 SolidWorks 或实物的测量噪声。图中的区间是条件于选定超参数的 GP 预测区间，不包含超参数估计的不确定性。

SolidWorks CSV 的 Lxy/Lxz/Lyz 按正张量记数法输出，URDF 输出列已对非对角项取负号。使用预测值前需确认坐标系2与 URDF 小腿 link 坐标轴对齐。主轴方向未直接拟合，URDF 使用的是 link 坐标系下的惯性张量。

物理检查：预测网格有效 301/301 点；最小特征值 0.0012609227 kg·m²；最小三角不等式裕量 0.0010532803 kg·m²；全部有效：True。
