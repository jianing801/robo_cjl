# RS04 大腿结构 GP 拟合

模型唯一标识：`RS04_thigh_URDF_GP`。该文件夹只包含 RS04 大腿结构代理模型，与其他电机型号及版本的 GP 参数分开保存。

坐标系1；输入15个SW点，实测长度 0.26–0.40 m。预测域为0.25–0.40 m，0.25–0.26 m为外推区，无扫描点验证。

SW扫描输入：`data/RS04_thigh_SW_scan_20261016_225528.csv`；SHA-256：`1ca00be43b007ad831c2d9963edef6a772380482a8cc6f206e2c2338589bee74`。所有15个扫描点均用于拟合；精度通过嵌套留一交叉验证评估，不单独留出测试点。

本包只拟合结构质量属性，不修改、复制或合并电机转矩—转速曲线，也不自动改动优化候选入口或仿真器设置。

## 任意长度直接预测

拟合脚本直接读取原始SW扫描CSV；`output/gp_models.json` 保存可复现的GP参数。`predict_rs04_thigh_gp.py` 用GP参数直接计算任意输入腿长，不通过301点密集表查值。示例：`python predict_rs04_thigh_gp.py --length-m 0.25 0.35 0.40`。

质量、质心 xyz 和质心处惯性张量的6个独立分量分别用 Matérn 5/2 高斯过程拟合。核长度尺度和噪声项在由粗到细的对数网格上，以精确边际似然最小值选择。各输出单独标准化。该实现仅依赖 NumPy。

精度采用嵌套留一交叉验证：每折留出1点，并在其余14点重新选择超参数。它不是独立外部测试集。拟合观测噪声是 GP 正则化参数，不代表 SolidWorks 或实物的测量噪声。图中的区间是条件于选定超参数的 GP 预测区间，不包含超参数估计的不确定性。

SolidWorks CSV 的 Lxy/Lxz/Lyz 按正张量记数法输出，URDF 输出列已对非对角项取负号。使用预测值前需确认坐标系1与 URDF 大腿 link 坐标轴对齐。主轴方向未直接拟合，URDF 使用的是 link 坐标系下的惯性张量。

物理检查：预测网格有效 301/301 点；最小特征值 0.0029048423 kg·m²；最小三角不等式裕量 0.0011288888 kg·m²；全部有效：True。

## 文件

- `gp_dense_predictions_301.csv`：301点预测均值、标准差、URDF惯性分量和物理检查，仅供绘图/检查。
- `gp_loo_cv_metrics.csv`、`gp_loo_predictions.csv`：RS04 嵌套留一交叉验证精度和逐点预测。
- `gp_model_metadata.csv`、`gp_models.json`：RS04核参数和可复现模型参数，包含唯一模型标识。
- `RS04_thigh_GP_mass_COM.svg`、`RS04_thigh_GP_inertia.svg`：RS04矢量拟合图。
- `fit_rs04_thigh_gp.py`：本次 GP 拟合实现。
- `predict_rs04_thigh_gp.py`：从 GP 参数对新长度直接计算预测。
