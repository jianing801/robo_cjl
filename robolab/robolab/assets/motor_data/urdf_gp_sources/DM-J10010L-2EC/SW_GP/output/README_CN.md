# DM-J10010L-2EC 大腿装配体 URDF 参数 GP 拟合

模型唯一标识：`DM-J10010L-2EC_thigh_URDF_real_curve_GP`。这是 10010L 独立保存的 GP 结构代理模型，不读取多项式模型参数。

坐标系1；输入15个SW点，实测长度 0.26–0.40 m。预测域为0.25–0.40 m，0.25–0.26 m为外推区，无扫描点验证。

SW扫描输入：`data/10010L_SW_scan_20261014_234815.csv`；SHA-256：`632bc8e76efa359d4ec8f4730bbd11e1cece25a21f303d0695f205ec743b3416`。15个样本均参与最终拟合，没有独立留出测试集；交叉验证采用嵌套留一法。早期独立多项式结果已归档在 `../../../archive_legacy/DM10010L_URDF真实曲线版/`，不作为当前预测入口。

执行器包络标识：`DM-J10010L-2EC`，独立副本保存在 `motor_curve/`。包络当前为48 V、120 N·m峰值限幅、200 rpm空载转速锚点的参数模型，并非厂家实测的完整全速扭矩包络。

## 任意长度直接预测

`output/gp_models.json` 保存可复现的GP参数；`predict_10010l_thigh_gp.py` 从这些参数直接计算任意输入大腿长度，不需要从301点密集表中查表。示例：`python predict_10010l_thigh_gp.py --length-m 0.25 0.325 0.40`。该命令行预测器尚未自动接入外部 BO 脚本。标准化训练CSV是原始15个SW样本的便于检查副本，不是优化期间的查表文件。

质量、质心 xyz 和质心处惯性张量的6个独立分量分别用 Matérn 5/2 高斯过程拟合。核长度尺度和噪声项在由粗到细的对数网格上，以精确边际似然最小值选择。各输出单独标准化。该实现仅依赖 NumPy。

精度采用嵌套留一交叉验证：每折留出1点，并在其余14点重新选择超参数。它不是独立外部测试集。拟合观测噪声是 GP 正则化参数，不代表 SolidWorks 或实物的测量噪声。图中的区间是条件于选定超参数的 GP 预测区间，不包含超参数估计的不确定性。

SolidWorks CSV 的 Lxy/Lxz/Lyz 按正张量记数法输出，URDF 输出列已对非对角项取负号。使用预测值前需确认坐标系1与 URDF 大腿 link 坐标轴对齐。主轴方向未直接拟合，URDF 使用的是 link 坐标系下的惯性张量。

物理检查：预测网格有效 301/301 点；最小特征值 0.0025381621 kg·m²；最小三角不等式裕量 0.00082557432 kg·m²；全部有效：True。

## 文件

- `gp_dense_predictions_301.csv`：301点预测均值、标准差、URDF惯性分量和物理检查，仅供绘图/检查。
- `gp_loo_cv_metrics.csv`、`gp_loo_predictions.csv`：嵌套留一交叉验证精度和逐点预测。
- `gp_model_metadata.csv`、`gp_models.json`：核参数和可复现模型参数，包含唯一模型标识。
- `DMJ10010L_thigh_GP_mass_COM.svg`、`DMJ10010L_thigh_GP_inertia.svg`：GP矢量拟合图。
- `fit_10010l_thigh_gp.py`：独立运行的 NumPy 拟合实现。
- `predict_10010l_thigh_gp.py`：从 GP 参数对新腿长直接计算预测。
